# MLI Connect: Concept Demo

A clickable concept demo of MLI Connect, a mobile app idea for Misr Life Insurance, prepared by Lynkrs.

- Open it: https://bob-elhasan.github.io/mli-connect-demo/
- Everything is simulated: codes, ID checks, face match, payment, e-signature and notifications. The sign-in code is always 123456.
- All customer data is fictional. Branch details and company information come from MLI's public website.
- This is not an MLI service and sells nothing.

This repo holds only the built site (HTML, scripts, fonts). The source lives in a separate private repo.
